# 26-2학기 군사공학 대시보드

2026학년도 2학기 군사공학(4학년) 과목 운영 페이지.
대시보드에서 아래 두 가지로 들어간다.

- **팀티칭 편성기** — 편성 요약과 교수별·교반별 수업진도표 생성
- **공유 자료실 (Google Drive)** — 교육진도표, 수업계획표, 교수별 점수 입력 스프레드시트

**https://hyunjoon0605.github.io/2026-2-military-engineering/**

## 편성 구조

- 교수 5명 / 교반 3개 / 타임 5개, 타임당 5회 (실수업 25회)
- 한 타임에 3명 수업, 2명 휴식 → 각 교수는 수업 3회(교반별 1회) + 휴식 2회
- 각 교수는 **1교반 → 2교반 → 3교반** 순으로 이동
- 순서(1교반 수강 기준): **기계 → 전자 → 시스템 → 환경 → 토목**

| 타임 | 기간 | 1교반 | 2교반 | 3교반 | 휴식 |
|---|---|---|---|---|---|
| T1 | 9/1 ~ 9/15 | 기계 | 토목 | 환경 | 전자, 시스템 |
| T2 | 9/17 ~ 10/13 | 전자 | 기계 | 토목 | 시스템, 환경 |
| T3 | 10/20 ~ 11/24 | 시스템 | 전자 | 기계 | 환경, 토목 |
| T4 | 12/1 ~ 12/15 | 환경 | 시스템 | 전자 | 기계, 토목 |
| T5 | 12/17 ~ 12/31 | 토목 | 환경 | 시스템 | 기계, 전자 |

담당 교수 — 기계 김주희 대령 / 전자 이무현 대위 / 시스템 김현준 대위 /
토목 김연재 대위 / 환경 정상조 대령

## 사용법

대시보드에서 `팀티칭 편성기` 배너를 누르면 편성 화면으로 들어가고,
좌측 상단 `대시보드` 버튼으로 돌아온다. 편성 화면은 주소 뒤에 `#tool`이
붙으므로 그 주소를 바로 공유해도 된다.

편성 화면 상단에서 학사일정(1안 또는 특강일 임의 지정)과 담당 순서를 정하면
아래 세 가지가 자동으로 생성된다.

- **편성 요약** — 타임별 교반 배정과 휴식자
- **교수별 진도표** — 분야 배너로 선택, 본인 담당 회차만 색으로 표시
- **교반별 진도표** — 교반 선택, 회차마다 담당 교수를 분야색으로 표시

`인쇄 / PDF 저장`을 누르면 A4 한 장에 한 표씩 출력된다.
휴대폰에서는 서식 열이 접히고 핵심 4개 열만 표시된다.

## 수정

`index.html` 한 파일로 동작한다. 편성 기본값은 파일 내 `state` 객체에 있다.

| 항목 | 위치 |
|---|---|
| 담당 순서 기본값 | `state.order` |
| 교수명 | `DEFAULT_NAMES` |
| 특강일 기본값(1안) | `PLANS` |
| 드라이브 폴더 주소 | `card-drive`의 `href` |
| 수업 미실시일 | `FIXED` |
| 학사일정 주차·날짜 | `WEEKS` |
